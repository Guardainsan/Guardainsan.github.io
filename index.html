Start with the contract auditor

A contract auditor that won't flag a clause without quoting it

Solo project
  • Python
  • LangChain
  • Chroma
  • BM25 + embeddings
  • Gemini 2.5 Flash
  • FastAPI

It reads a PDF, HTML or text contract, checks it for 8 risk types, and quotes the exact clause behind each finding with a page reference.

What I built

The whole pipeline: clause-aware chunking, local all-MiniLM-L6-v2 embeddings in Chroma, hybrid semantic and BM25 retrieval, one Gemini call per risk, an evaluation harness with hand-written answer keys, and a FastAPI web app on top.

The decision that mattered

If the model says a risk is there but can't quote the text, the code marks it as not present. In an audit, an invented risk does more damage than a missed one.

95.8%
23 of 24 checks correct across 3 hand-labelled test contracts. They were small enough that retrieval returned every chunk, so this measures the model's judgement, not retrieval ranking.

A lead scorer that won't call the model until it has real page text

Solo project
  • n8n
  • Google Sheets
  • Gemini structured output
  • Docker

An n8n workflow that reads leads from a Google Sheet, fetches each company's website, has Gemini score the company against an ideal-customer profile, and writes the result back to the sheet.

The decision that mattered

Four checks run before any token is spent: no company name, no website, a failed fetch, or under 250 characters of clean text. A page can return HTTP 200 and still be an empty JavaScript shell, so the last check counts the text instead of trusting the status code.

A classifier for 20 persuasion techniques in meme text, misses included

RMIT coursework, solo
  • PyTorch
  • Hugging Face Transformers
  • DistilBERT
  • scikit-learn

The model reads the text of a meme and predicts which of 20 persuasion techniques it uses. A second head marks where in the text each one appears.

The decision that mattered

Each technique gets its own sigmoid output and its own threshold, tuned on the dev set, because one meme can use several techniques at once. Before training I removed a record that appeared in both the training and test files.

What it got wrong

On the full 200-text test set, macro-F1 is 0.16. The model over-predicts: it tagged Exaggeration/Minimisation on every test text. Six techniques have three or fewer test examples, so their scores swing on a single hit.
